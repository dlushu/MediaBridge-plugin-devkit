# 元数据插件契约

通用模型（包、通道、动作、执行、缓存、webui）见 [plugin-contract.md](plugin-contract.md)；
本文只管 `metadata` 类型插件**额外**要遵守的：注册、取元数据、取分集、搜索的字段与动作。

---

## 一、动作总表


动作与"面板从上游元数据取用的东西"**一一对应**。

| 动作 | 入参 | 出参 | 必需性 |
|---|---|---|---|
| 注册 | — | 域 id + 能力清单 + 剧集式 / 电影式 + 条目外链模板 | 必需 |
| 取元数据 | 条目坐标（一次一个） | 规范字段 + 成败（成功 `{ok:true,…}`；失败回 `{ok:false,error:{code,message}}` 或 throw，见总契约第十节） | 必需 |
| 取一季分集 | 条目坐标 + 季号 | 分集列表 | 必需 |
| 搜索 | 搜索词 | 候选列表 | 必需 |
| webui（`http`） | `{method, path, query, body, contentType}` | `{status?, body, contentType?}` | 可选 |

### "取元数据"要提供的字段（按用途分组）

- **身份**：条目 id、类型（电影 / 剧集）
- **名字与时间**：主标题、原始标题、年份、首播日期
- **给源站点搜索用的词**（现为 `searchTitle`：主标题没中文时回退中文别名）
- **简介**（面板按长度上限裁剪）
- **图片**：海报、背景，以及详情页用的图集
- **分类**：类型名列表 **与带 id 的类型项**（客户端要能点进"类型"，只给名字点不进去）
- **规模与评分**：季数、评分
- **详情页那一批**：标语、状态、时长、分级、制作公司（**必须带 id**）、制片国家、关键词、
  外部 id（imdb / tvdb / wikidata）、预告、演职、相似推荐

**「相似推荐」每一项给这几个**（面板只读这几个，别的字段面板不认）：`entryId`（本域自己的条目编号）、
`type`、`title`、`year`、`overview`、`communityRating`、`posterPath`、`backdropPath`。
面板把每一项按**本条目的域**拼成条目 Id（客户端据此点进详情），所以它们必须与正常条目同一套编号。
拿不到就**如实回空数组**，别编 —— 少了这一栏客户端只是不显示，编了则会点进一个不存在的条目。

### "取一季分集"要提供的字段

集号、集名、简介、首播、剧照、评分、时长。**拿不到就如实留空**。

### 能力申报

`注册` 时申报**它会哪些、缺哪些**（即上面那两份字段清单 + 剧集式 / 电影式）。
面板按申报决定给客户端什么、缺的如实留空。

### 条目外链申报

`注册` 还可带 `links`：`[{ name, url }]`，给它这个域的条目配"去站点上看"这类外链
（面板把它转成客户端列表项上的外部链接）。

- `url` 是**模板**，两个占位符由面板替换：`{type}` → `movie` / `tv`（Emby 用的口径）、
  `{id}` → 该条目的编号（面板对它做 URL 编码后再填）。
- 例：`[{ name: '站点', url: 'https://<站点>/item/{id}' }]`。
- **面板不认识任何具体站点**：插件不申报就没有这一条，不猜、不兜底；
  条目编号拿不到时也如实不出这一条。
- `name` 与 `url` 缺一即忽略这一项；整个字段缺省即"没有外链"。
- 只放**能从条目编号推出来**的链接（例如站点自己的条目页）。
  需要额外号码的（如 IMDb 的 `tt` 号）走"取元数据"的外部 id，不在这里拼。

⚠️ **不属于插件、不要塞进来**：图片的**代取与签名**（面板为客户端取图，见
[ADR-0013](https://github.com/dlushu/media-bridge-panel/blob/main/docs/adr/0013-image-endpoint-signing.md)）、各类缓存（各自管各自的，见总契约第八节）、
Emby 的 DTO 形状（面板负责转换，见 [ADR-0007](https://github.com/dlushu/media-bridge-panel/blob/main/docs/adr/0007-emby-dto-shape.md)）。

### 条目 Id

**形状由面板统一规定**，插件只提供"条目 id"（它自己的编号）+ 声明是剧集式还是电影式。
坐标的编解码**不下放给插件** —— 否则面板得懂每个域的坐标语法。
理由：条目 Id 与客户端、进度库的键、首页插件的条目契约绑在一起。
